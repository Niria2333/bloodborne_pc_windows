## 启动器和画质

语言、全屏、垂直同步、独立 A/B 与 X/Y 互换及命名生命周期有自动回归覆盖。垂直同步使用现有 `BB_PRESENT_MODE`：开启为 FIFO，关闭为 Immediate；不支持 Immediate 时渲染器回退到 FIFO。测试验证偏好保存、启动环境、互斥命令行参数与重启后的设置传递，未新增游戏内撕裂或延迟测量。

图形选项保存、只合并修改字段、无效值拒绝、重启后保留选择和分辨率/质量分离均通过 Python 检查。目录检测与相对路径保存验证覆盖本地目录移动、保留有效外部目录和省略 `--game` 的情况。

启动器尺寸为 780×620。实际 Tk 组件检查通过：垂直同步及两组独立按键勾选框可见；四种按键组合的动态提示、保存与启动参数正确。修改器默认窗口为 560×620，内容所需高度 565，小于最小窗口高度 590；4 项界面测试覆盖显式应用、输入校验与还原失败重试。

30/60/90/`uncap` 补丁与 vblank 参数一致性通过；90 FPS 和没有独立 60 FPS 限制的显示器档位未做完整关卡性能验证。上游 Linux 性能数字不用于此处 Windows 结论。

### Windows 平稳 60 帧

Windows 等待改用高精度 waitable timer，VideoOut 的帧提交与 tick deadline 也使用该等待；创建或设置失败时保留兼容回退。普通 Windows 计时器曾使约 16.7 ms 的等待变成约 31 ms，平均帧率并不能反映这些长帧。

新增“平稳 60 帧（120 Hz 全屏）”选项，仅同时选择 60 帧、全屏和垂直同步时生效。内部采用动态游戏时序补丁（`uncap`），另限实际提交为 60 FPS，请求当前桌面分辨率的 120 Hz 全屏模式并使用两帧 GPU 管线缓冲；不生成插帧，也不把游戏速度加倍。不支持该显示模式时保留桌面模式并记录警告，60 FPS 限制仍生效。正常退出恢复桌面模式。

2026-10-06 在相同 3840×2160 输出、FSR 4 v07 INT8 Balanced 和相同特效下，用官方 PresentMon 对显示帧时间做独立采样。普通固定 60 帧对照也已包含高精度计时修复。预热后静止区间的显示平均为 60.0037 FPS、p99 为 16.7612 ms、独立 1% Low 为 55.02 FPS；镜头运动区间显示平均约 60 FPS、p99 为 16.7617 ms、独立 1% Low 为 58.20 FPS。这些数值是最慢 1% 显示时长的平均值取倒数，NVIDIA 浮窗的公式和窗口未知，不能保证其 Low 显示相同数值。

真实启动器另完成 120 秒短时运行和 20 秒显示模式检查；后者实测由 3840×2160@159.98 Hz 切换到 120 Hz，退出恢复 159.98 Hz。日志中的 `vblank 480 Hz, frame limit 60 FPS` 指内部调度 tick 与独立限帧，不是屏幕 480 Hz。原生 Present 调用采样用于核对最终启动器行为，不能替代显示帧时间。测量范围、公式、复测方法与局限见 [WINDOWS_FRAME_PACING.md](WINDOWS_FRAME_PACING.md)。

## Windows 修改器

支持生命和体力补满、指定血之回响与已有物品数量。已对本机 CUSA03023 1.09 的四处原始指令核验，连接时再次校验版本、进程路径和代码所有权。

28 项测试覆盖数值范围、版本不匹配、冲突拒绝、线程暂停及执行位置重试、失败回滚和正常恢复。独立合成进程验证四项 Hook 的实际 Windows 内存写入、物品代码两条进入路径，并在另一线程持续执行时连续重新配置 20 次。测试不包含游戏数据，未逐一实测游戏内所有场景、死亡方式和物品种类。用法、限制及 Shiningami 社区表来源见 [WINDOWS_TRAINER.md](WINDOWS_TRAINER.md)。

## FSR 4 与 FSR 4.1.1

FSR 4 v07 INT8 下载工具使用固定 Q2RTX 提交 `ae8d628fae208813172446d1e49ed94150b04658`，182 个上游资源大小和 SHA256 校验通过，194 个 SPIR-V 验证通过（包含优化后文件）。六种模型预设和 1080/2160 tier 的安装报告为 `fsr4_shaders/ASSET_INSTALL_REPORT.json`。资源不提交到公开仓库。

RTX 4070 Ti 独立 `fsr4-bench` 完成 `1280×720 → 1920×1080 Quality` 8 帧运行，退出码 0。本机日志为 `out/fsr4-bench-1080.log`。随后完成上述 FSR 4 v07 INT8 Balanced 的 4K 游戏内短时帧时间验证。长期完整游戏、全预设或跨版本图像一致性仍未验证。

**FSR 4.1.1 Windows 适配未完成。** 本机不支持 `VK_VALVE_shader_mixed_float_dot_product`；真实 4.1.1 捕获模型和可验证的便携 shader 路径尚未落地。启动器保留旧 ini 标识但不允许新选 4.1.1；条件不满足时运行时回退 FSR 3.1。现有 FSR 4 v07 结果不能证明 4.1.1 支持。
