# Windows 验证记录

日期：2026-10-05（Asia/Hong_Kong）。上游基线：`5224a6d137d8c4efaab69f2412f4bb86227b9ab8`。Windows 源码分支：`codex/windows-port`。

本记录汇总开发时实际结果，不承诺其他电脑或全游戏达到相同表现。公开发布仅含源码；本机运行包、游戏数据、存档和原始日志不上传。

## 验证环境

- Windows 11 x64，版本 10.0.26220。
- Intel Core i5-13600KF，约 16 GB 系统内存。
- NVIDIA GeForce RTX 4070 Ti，12 GB 显存，驱动 617.14。
- MSYS2 UCRT64，GCC 16.2、CMake 4.4、Ninja，Python 3.14。
- 已解密 CUSA03023《血源：老猎人版》，`APP_VER=01.09`。启动器也接受上游 CUSA03173 1.09；本机游戏验证使用的是 CUSA03023。

最终运行 `build_windows.ps1 -Test`，完整编译和 **16/16 项 CTest、74/74 项 Python 测试**通过。开发机结果日志为 `out/windows-publication-validation.log`，该文件属于本地生成物，不随源码发布。

另外，AvPlayer 针对真实 H.264/AAC 合成测试素材完成 100 次满缓冲跳过和 5 次禁用音频 EOF 检查，修复停止线程重复 join、EOF 顺序及队列/源锁生命周期后通过。该独立工具测试不包含在上述 16 项 CTest 总数中。

## 启动器和画质

语言、全屏、Xbox 映射及命名生命周期有自动回归覆盖。图形选项保存、只合并修改字段、无效值拒绝、重启后保留选择和分辨率/质量分离均通过 Python 检查。

最终启动器尺寸为 780×620，最后布局改动做了源码检查和组件烟测；此前 780×740 版本经过窗口截图检查。缩短窗口及最终分离输出设置后尚未再次完成整窗可见布局验证。

30/60/90/`uncap` 补丁与 vblank 参数一致性通过；90 和 `uncap` 没有实际关卡帧率验证。上游 Linux 性能数字不用于此处 Windows 结论。

## FSR 4 与 FSR 4.1.1

FSR 4 v07 INT8 下载工具使用固定 Q2RTX 提交 `ae8d628fae208813172446d1e49ed94150b04658`，182 个上游资源大小和 SHA256 校验通过，194 个 SPIR-V 验证通过（包含优化后文件）。六种模型预设和 1080/2160 tier 的安装报告为 `fsr4_shaders/ASSET_INSTALL_REPORT.json`。资源不提交到公开仓库。

RTX 4070 Ti 独立 `fsr4-bench` 完成 `1280×720 → 1920×1080 Quality` 8 帧运行，退出码 0。本机日志为 `out/fsr4-bench-1080.log`。没有 FSR 4 游戏内、4K、全预设或跨版本图像一致性验证。

**FSR 4.1.1 Windows 适配未完成。** 本机不支持 `VK_VALVE_shader_mixed_float_dot_product`；真实 4.1.1 捕获模型和可验证的便携 shader 路径尚未落地。启动器保留旧 ini 标识但不允许新选 4.1.1；条件不满足时运行时回退 FSR 3.1。现有 FSR 4 v07 结果不能证明 4.1.1 支持。

## 尚未验证

- 4K 实际关卡持续 60 FPS，以及所有输出/超分/质量组合。
- 完整通关、长时间稳定性、内存峰值和各种场景/特效正确性。
- 其他 Windows 版本、其他电脑/显卡、全部手柄及完整音频质量。
- 游戏存档与不同发行版本之间的全面兼容性。

Windows 稀疏共享映射的 `SEC_RESERVE` 已提交页承诺保持到进程退出；底层释放/复用测试不等于实际游戏长期内存预算测量。标题 60 FPS、补丁目标和 4K 交换链初始化也不能证明 4K 关卡能稳定 60 FPS。
